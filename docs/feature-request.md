# 💡 How to Suggest a New Feature (Feature Request)

Have an idea for improving NewTube? Please suggest it using these steps:

1.   **Go to the Issues Page:**

     -    Click here to go to the [NewTube Issues](https://github.com/AzPepoze/NewTube/issues?q=state%3Aopen%20label%3Afeature request) page on GitHub.

2.   **Create a New Issue:**

     -    Click the green "New issue" button.

3.   **Choose a Template (if available):**

     -    If there's a Feature Request template, please use it.

4.   **Provide Details:**

     -    **Issue Title:** Create a title that clearly describes the feature you're suggesting.
     -    **Describe the Feature:** Explain what the feature is, why it would be useful, and how you imagine it working.

5.   **Add Labels:**

     -    Select the `Feature Request` label. You can add other relevant labels too.

6.   **Submit the Issue:**
     -    Review your suggestion and click "Submit new issue".

We appreciate your ideas for making NewTube better! ✨
