# 🐛 How to Report a Bug

If you encounter an issue while using NewTube, please report it following these steps:

1.   **Go to the Issues Page:**

     -    Click here to go to the <a href="https://github.com/AzPepoze/NewTube/issues/new?template=bug_report.yml" target="_blank">NewTube Issues</a> page on GitHub.

2.   **Provide Details:**

3.   **Add Labels:**

     -    Select relevant labels, the browser name (e.g., `chrome`, `firefox`), or the affected component.

4.   **Submit the Issue:**
     -    Review the information and click "Create".

Thank you for helping report issues! 🙏
